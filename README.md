# Shade Messenger Desktop

Официальная сборка приложения **Shade Messenger** для Windows (x64).

## 🚀 Скачать
- [**Shade.exe**](./Shade.exe?raw=true) (Портативная версия — не требует установки, готова к запуску).

---

## ⚡ Особенности
- **Голосовые каналы и демонстрация экрана**: высокое качество звука, шумоподавление, WebRTC.
- **Мгновенный обмен сообщениями**: поддержка медиафайлов, предпросмотр, цитирование и подсветка ответов.
- **Локальное кеширование**: 0 мс задержки при переключении каналов и открытии медиа с вашего диска.
- **Персонализация**: кадрирование аватаров, темная тема, индикация статусов.

---

Разработано командой Shade.
